## 2. Naming Lock 條款（星曜版）

> 「本表為星曜、輔星、煞星、雜曜命名唯一標準。除 `star_name_registry` 外，系統任何層級不得新增獨立星曜名稱作主鍵。現代俗稱、五行屬性別稱（如印星、財星、蔭星）只能作 `legacy_aliases`，不可取代 `standard_key` 進入運算層或報告輸出主鍵。」

### 執行守則：
1. **SSOT 優先**：`standard_key` 永遠由 `core_engine.static_lookup_tables` 決定。
2. **語義收束**：`legacy_aliases` 只可用於 OCR 識別、白話提問對齊及解讀說明。
3. **運算隔離**：禁止 `legacy_aliases` 進入 `sihua_matrix`、`star_strength_table` 等計算型欄位。
4. **歧義處理**：如「將星」、「小耗」等同名異義項，必須強制標註所屬系統（如 `jiangqian_12shen`）。
