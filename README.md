## 已修復項目（相對舊版）— 全部已落地於本倉庫

核心引擎 ① 與同步層 ③ 已修復以下 7 處（皆寫入 JSON 公式／查表，無硬編碼）：

1. **紫微差數法** — 依「生日」非生月：`q=ceil(生日/局數); c=q*局數−生日; steps=(q−c if c奇 else q+c); 紫微idx=(2+steps−1)%12`
2. **紫微系逆行** — 天機(Z−1)/太陽(Z−3)/武曲(Z−4)/天同(Z−5)/廉貞(Z−8)，皆 +12%12
3. **天府** — `(4−紫微+12)%12`（寅申軸對稱）；舊式 `12−紫微` / `10−紫微` 皆錯，已棄用
4. **擎羊/陀羅** — 擎羊=`(祿存+1)%12`、陀羅=`(祿存−1+12)%12`
5. **左輔/右弼** — 左輔=`(4+月idx)%12`、右弼=`(10−月idx+12)%12`
6. **火星/鈴星起例** — 年支三合定位：申子辰→火寅/鈴戌；寅午戌→火丑/鈴卯；巳酉丑→火卯/鈴戌；亥卯未→火酉/鈴戌
7. **晚子時換日** — 23:00–23:59 晚子→農曆日+1（跨月月+1、跨年年+1、年干支重取）；00:00–00:59 早子→日不變；時支恆=子(idx0)

斗君公式同步訂正為 `(太歲−生月+生時+24)%12`（逆生月減、順生時加；務必納生時項）。
