## 體用分層協議（南體北用）

**核心邏輯**：以南派「星曜格局」為**體**（天生個性、環境、潛能），以北派「四化飛星」為**用**（後天心念、行為選擇、事件觸機）。解讀遵循「先體後用、體優於用」原則。

### 體（南派三合星曜派・靜態骨架）
- 命身宮定位 → 格局範圍／人生舞台
- 十四主星廟旺利平陷 → 星性強弱／潛能上限
- 三方四正拱夾 → 支撐／衝擊之結構
- 六吉六煞（左右昌曲魁鉞、羊陀火鈴空劫）→ 助力／阻力
- 傳統格局（紫府同宮、機月同梁、殺破狼、鈴昌陀武…）→ 命之骨
- 命主／身主／五行局 → 先天氣稟
- **對應計算層**：`interpretation_engine_v1.1` S3~S6

### 用（北派四化飛星・動態能量流）
- **五層天干四化**：本命／大限／流年／流月／流日（定後天觸機）
- **宮干自化**：本命宮干四化回照本宮（見 S7b_zihua / core 21_zihua_self_transformation）
- **宮干四化（飛化）**：宮際能量牽引（定宮際關聯，不擴充 12 宮互飛矩陣）
- 祿權科忌四象 → 得（祿）／爭（權）／名（科）／失（忌）
- **對應計算層**：`interpretation_engine_v1.1` S7 + S7b
- **擴充禁令**：禁止 12 宮宮干互飛矩陣；`expansion_forbidden = true`

### 解讀順序（強制）
1. **先體**：格局是否成立？主星廟旺陷？三方四正是否得援？→ 出「基礎吉凶」
2. **後用**：四化落於何宮？祿忌相沖或相引？自化是否成立？→ 出「事件觸機／時位」
3. **體用並列**：體用衝突時（如格局成而四化沖破，或格局不成而四化引動）**不做單邊裁決**，並列呈現兩軌結論並附底層依據（F5 規則）。

### 權重與衝突政策

| 項目 | 值 | 說明 |
|---|---|---|
| body_weight | 0.5 | 南派三合權重 |
| use_weight | 0.5 | 北派四化權重 |

| forbidden | `expansion_forbidden` | 禁止以用蓋體、禁止單邊裁決、禁止 12 宮互飛 |
